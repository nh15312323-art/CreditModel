# 단계 4. 단변량·다변량 분석과 변수 진단

> 변수를 *하나씩* 보고, 다음엔 *함께* 보고, 마지막에 "이 변수를 모형에 넣어도 되는가"를 여러 근거로 결정한다. p-value 하나로 결정하지 않는다.

**연결 실습**: 노트북 `04_variable_diagnostics` · 코드 `creditlab.features.vif_table`, `compare_groups`, `leakage_suspects`, `VariableLog`

## 학습 목표

- 단변량 분석과 다변량 분석의 차이를 설명한다.
- Pearson·Spearman 상관과 범주형 연관성(Cramér's V)을 계산하고 한계를 말한다.
- 다중공선성, **VIF**, 조건수의 의미와 한계를 설명한다.
- 교란변수·상호작용·비선형성이 *나쁜 결론*을 만드는 방식을 설명한다.
- 변수 후보를 *업무 논리·가용성·안정성·품질·법/공정성* 기준으로 판단하고 기록한다.

## 1. 왜 생겼는가

변수를 하나씩만 보면 "연령이 높을수록 부도율이 낮다" 같은 단순한 결론에 이르지만, 현실에서는 변수끼리 얽혀 있다. 소득이 높은 사람이 대체로 나이도 많다면, 연령의 효과는 정말 연령 때문일까? 이런 *얽힘*을 다루기 위해 다변량 분석과 변수 진단 절차가 만들어졌다. 또 회귀 계수가 데이터가 조금 바뀔 때마다 부호가 뒤집히는 경험(다중공선성)이 *진단 도구*(VIF 등)의 필요성을 낳았다.

## 2. 왜 필요한가

- 상관이 높은 변수를 그대로 넣으면 **계수가 불안정**해지고 해석이 흔들린다(규제 모형에서 치명적).
- 교란변수를 놓치면 *변수의 진짜 효과*를 오해한다.
- 변수 선택 기준이 문서화되어야 검증자와 감독당국이 *왜 이 변수인가*를 이해한다.

## 3. 무엇을 하는가

| 분석 | 질문 | 도구 |
|---|---|---|
| 단변량 | 이 변수 하나는 어떻게 생겼나/타깃과 어떤 관계인가 | 분포, 구간별 부도율, IV(단계 5) |
| 이변량 | 두 변수는 얼마나 관련되나 | Pearson/Spearman, Cramér's V, 교차표 |
| 다변량 | 다른 변수를 통제해도 효과가 남는가 | 다변량 회귀, 상호작용 점검 |
| 진단 | 변수 집합에 중복·불안정이 있나 | VIF, 조건수, 상관행렬 |

## 4. 어떻게 작동하는가

### 4-1. 상관: 선형 관계의 세기

- **Pearson** 상관은 두 변수의 *선형* 관계를 잰다. 이상치에 민감하다.
- **Spearman** 상관은 *순위*로 바꿔 Pearson 을 계산한다. *단조* 관계(항상 증가/감소)면 1 또는 -1 에 가깝다.

**숫자 예제.** $x=1,2,3,4,5$, $y=x^2$ 이면 $y$ 는 $x$ 가 늘 때 항상 늘지만 직선은 아니다. Pearson $=0.981$, Spearman $=1.0$.

```python
import numpy as np
from scipy import stats

x = np.arange(1, 6)
y = x ** 2
pearson = np.corrcoef(x, y)[0, 1]
spearman = stats.spearmanr(x, y)[0]
print(round(pearson, 3), round(spearman, 3))
assert abs(pearson - 0.981) < 1e-3 and abs(spearman - 1.0) < 1e-12
```

상관이 0 이어도 관계가 없다는 뜻이 아니다. $y=x^2$ 를 0 을 중심으로 대칭 구간에서 보면 Pearson 이 0 에 가깝다. **산점도를 먼저 본다.**

### 4-2. 범주형 변수의 연관성

교차표로 범주별 부도율을 보고, 카이제곱 통계량으로 연관성을 요약한다. 표본 크기 영향을 줄인 *효과크기*가 **Cramér's V** 이다.

$$ V=\sqrt{\frac{\chi^2}{n\,\min(r-1,\,c-1)}} $$

단계 3 의 임차/자가 예제($\chi^2=8.89$, $n=2000$, 2×2 표)에서 $V=\sqrt{8.89/2000}\approx0.067$ 로, p-value 는 작아도 **연관의 세기는 약하다**.

### 4-3. 다중공선성과 VIF

변수 $X_j$ 를 *나머지 설명변수들로 회귀*했을 때의 결정계수를 $R_j^2$ 라 하면

$$ \mathrm{VIF}_j=\frac{1}{1-R_j^2} $$

$R^2=0.9$ 이면 VIF=10 이다. 두 변수만 있고 상관이 $r$ 이면 VIF $=1/(1-r^2)$ 이다. $r=0.95$ 일 때 약 10.3.

!!! note "VIF 기준은 관행이다"
    "5 또는 10 이상이면 문제" 라는 기준이 흔히 쓰이지만 보편 법칙이 아니다. 예측 목적이면 공선성이 있어도 예측 성능은 괜찮을 수 있고, *계수 해석과 안정성*이 목적일 때 더 문제가 된다. **조건수(condition number)** 는 설계행렬의 수치적 불안정성을 한 숫자로 보여 주는 또 다른 진단이다.

```python
import numpy as np

def vif(X):
    """각 열을 나머지 열로 회귀한 R²에서 VIF 계산 (절편 포함, 최소제곱)."""
    X = np.asarray(X, float)
    out = []
    for j in range(X.shape[1]):
        others = np.delete(X, j, axis=1)
        A = np.c_[np.ones(len(X)), others]
        coef, *_ = np.linalg.lstsq(A, X[:, j], rcond=None)
        resid = X[:, j] - A @ coef
        r2 = 1 - resid.var() / X[:, j].var()
        out.append(1 / (1 - r2))
    return np.array(out)

rng = np.random.default_rng(0)
x1 = rng.normal(size=2000)
x2 = x1 + 0.33 * rng.normal(size=2000)      # x1 과 상관 약 0.95
x3 = rng.normal(size=2000)                   # 독립
v = vif(np.c_[x1, x2, x3])
print(np.round(v, 1))
assert 8 < v[0] < 13 and 8 < v[1] < 13 and v[2] < 1.2
```

### 4-4. 교란변수와 심슨의 역설

**교란변수**는 입력 변수와 타깃 *모두*에 영향을 주어 겉보기 관계를 만든다. 다음은 가상 데이터다(채널 A=온라인, B=지점).

| 소득 구간 | 채널 | 신청 | 부도 | 부도율 |
|---|---|---|---|---|
| 고소득 | A | 100 | 2 | 2.0% |
| 고소득 | B | 700 | 21 | 3.0% |
| 저소득 | A | 700 | 63 | 9.0% |
| 저소득 | B | 100 | 10 | 10.0% |

각 소득 구간 *안에서는* A 가 B 보다 부도율이 낮다(2% < 3%, 9% < 10%). 그러나 전체로 합치면 A: 65/800 = 8.125%, B: 31/800 = 3.875% 로 **A 가 더 나빠 보인다**. A 채널에 저소득 신청이 몰려 있기 때문이다. 이것이 *심슨의 역설*이다. 전체 부도율만 비교해 "온라인 채널은 위험하다"고 결론내리면 틀린다.

```python
a = [(100, 2), (700, 63)]
b = [(700, 21), (100, 10)]
assert [d / n for n, d in a] == [0.02, 0.09] and [d / n for n, d in b] == [0.03, 0.10]
assert sum(d for _, d in a) / 800 == 0.08125 and sum(d for _, d in b) / 800 == 0.03875
```

**상호작용**은 한 변수의 효과가 *다른 변수 값에 따라 달라지는* 것이다(예: 연체 이력의 영향이 신용한도 구간에 따라 다름). 로지스틱 회귀는 명시하지 않으면 상호작용을 *모른다*. 트리 모형은 자동으로 포착한다.

### 4-5. 변수 선정은 다중 기준의 판단이다

| 기준 | 질문 | 예 |
|---|---|---|
| 업무 논리 | 부호·방향이 상식과 맞는가 | 연체가 늘수록 위험 증가 |
| 가용성 | 운영 시점에 안정적으로 얻을 수 있나 | 심사 시점에 확보 불가한 값 제외 |
| 데이터 품질 | 결측·오류·정의 변경이 심하지 않은가 | 정의가 바뀐 변수는 위험 |
| 안정성 | 기간별 분포·관계가 안정적인가 | 기간별 IV/부도율 일관성(단계 5, 10) |
| 예측력 | 단변량·다변량에서 정보가 있는가 | IV, 단변량 AUROC |
| 중복성 | 다른 변수와 정보가 겹치는가 | 상관, VIF |
| 법·공정성 | 사용 금지/제한 변수·대리변수 위험은 없는가 | 민감 속성의 직·간접 사용 검토 |
| 설명가능성 | 고객·감독당국에게 설명할 수 있나 | 규제 모형에서 특히 중요 |

**단계적 선택(stepwise)** 은 자동화되어 편리하지만, 같은 데이터에서 변수를 고르고 p-value 를 보고하면 *낙관적 편향*이 생긴다. 자동 선택 결과도 위 기준으로 *사람이 검토*하고, 선택 과정 자체를 검증 데이터에서 재현해야 한다(단계 8).

## 5. 가정

- Pearson 상관은 선형·이상치 영향이 적은 관계를 가정한다.
- VIF 는 선형 모형의 선형 종속성만 잰다.
- 다변량 효과는 *모형이 옳게 지정되었다*는 가정(선형성, 포함된 교란변수) 하에서 해석된다.
- 관측 데이터에서 교란변수를 *모두* 통제했다는 보장은 없다.

## 6. 한계와 오용

!!! warning "자주 하는 오용"
    - 상관을 인과로 해석한다("이 변수를 올리면 부도가 줄어든다").
    - p-value 만 보고 변수를 선택하거나 제외한다.
    - 상관행렬 하나로 "공선성 없음"을 선언한다(3개 이상 변수의 선형 결합 공선성은 쌍 상관에서 안 보인다).
    - 부도율이 *전체로* 높은 변수를 "위험 변수"로 판단한다(심슨의 역설).
    - 상관이 높은 변수를 *무조건* 삭제한다(업무상 둘 다 필요하면 결합하거나 대표 변수를 정한다).

## 7. 대안 및 비교

| 문제 | 대응 | 비교 |
|---|---|---|
| 공선성 | 변수 제거 / 변수 결합 / 규제(L2) / 요인분석·PCA | PCA 는 해석을 잃는다 |
| 비선형 | 비닝·WOE / 스플라인 / 트리 | 스코어카드는 비닝이 비선형을 흡수 |
| 상호작용 | 명시적 항 추가 / 트리 | 항을 늘리면 해석 비용 증가 |
| 변수 선택 | 필터(IV·상관) / 래퍼(단계적) / 임베디드(L1) | 임베디드는 모형 안에서 선택해 누수 위험이 낮음 |

## 8. 실무 적용

- **규제 로지스틱 CSS**: 계수의 부호가 업무 논리와 같은지(예: WOE 변수의 계수 방향)를 확인하고, 공선성이 있으면 변수 하나를 선택한다. 변수 선정 근거표(**유지/제외 이유**)가 필수 산출물이다.
- **AI 모형**: 공선성에 비교적 강하지만 *설명가능성*(SHAP)에서 상관 변수끼리 기여도가 나뉘어 해석이 어렵다. 중복 변수를 정리하면 해석이 쉬워진다.
- 변수 후보 → 판단 → 결과를 **변수 선정 근거표**로 남긴다(캡스톤 산출물 5).
