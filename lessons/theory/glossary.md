# 용어 사전

> 검색창에 용어(한글·영어·약어)를 입력하면 표가 걸러진다. 각 용어의 자세한 설명은 오른쪽 단계 링크에서 읽는다.

## 문제 정의와 데이터

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| 부도(default, bad) | 사전에 정한 *관찰기간 안에* 정의된 연체·채무불이행에 도달한 사건. 이 프로그램에서 target=1 | [1](stage_01.html) |
| 정상(good) | 관찰기간 동안 부도가 아닌 건. target=0 | [1](stage_01.html) |
| 관찰시점·성과기간 | 변수를 측정하는 시점과, 그 뒤 부도 여부를 지켜보는 기간 | [1](stage_01.html) |
| 모집단 | 모형을 쓸 대상 전체. 학습 표본이 이와 다르면 성능이 틀어진다 | [1](stage_01.html) |
| 데이터 누수(leakage) | 예측 시점에 알 수 없는 정보가 학습·평가에 들어가 성능이 거짓으로 좋아지는 것 | [8](stage_08.html) |
| 결측(MCAR/MAR/MNAR) | 값이 없는 이유의 분류. 무작위 / 관측변수에 의존 / 값 자체에 의존 | [2](stage_02.html) |
| 데이터 사전 | 변수명·정의·단위·허용범위·출처를 적은 문서 | [2](stage_02.html) |
| cleaning_log | 정제 과정에서 바꾼 값·행을 *원본을 보존한 채* 기록한 로그 | [2](stage_02.html) |
| 선택 편향(selection bias) | 과거 승인된 사람만 결과가 관찰되어 표본이 모집단을 대표하지 못하는 문제 | [15](stage_15.html) |
| 거절 추론(reject inference) | 거절자의 결과를 가정·추가정보로 추정하려는 시도. 가정에 의존한다 | [15](stage_15.html) |

## 통계 기초

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| 신뢰구간(Wilson) | 비율의 불확실성 범위. 표본이 작을수록 넓다 | [3](stage_03.html) |
| 부트스트랩 | 복원추출을 반복해 지표의 변동을 추정 | [9](stage_09.html) |
| 오즈(odds) | 확률 $p$ 에 대해 $p/(1-p)$ | [6](stage_06.html) |
| 로그오즈(logit) | 오즈의 자연로그. 로지스틱 회귀가 선형으로 모형화하는 대상 | [6](stage_06.html) |
| 상관·다중공선성 | 변수들이 서로 비슷한 정보를 가져 계수가 불안정해지는 현상 | [4](stage_04.html) |
| VIF | 다중공선성 진단 지표. 클수록 심각 | [4](stage_04.html) |
| p-value | 귀무가설이 참이라 가정할 때 관측만큼 극단적인 결과가 나올 확률. 가설이 참일 확률이 아니다 | [14](stage_14.html) |
| 순열검정 | 라벨을 섞어 귀무분포를 직접 만드는 검정 | [14](stage_14.html) |
| 다중검정 | 여러 가설을 동시에 검정할 때 우연한 유의 결과가 늘어나는 문제 | [14](stage_14.html) |
| FDR / BH | 거짓 발견 비율 통제 / 이를 위한 Benjamini–Hochberg 절차 | [14](stage_14.html) |

## 변수 처리와 스코어카드

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| 비닝(binning) | 연속형 변수를 구간으로 나누는 일 | [5](stage_05.html) |
| WOE | 구간의 $\ln(\%bad/\%good)$. 이 프로그램에서는 높을수록 위험 | [5](stage_05.html) |
| IV | 변수 전체의 정보량 $\sum(\%bad-\%good)\cdot WOE$. 변수 선택의 참고 지표 | [5](stage_05.html) |
| 단조성 | 변수 값이 커질 때 위험이 한 방향으로만 변하는 성질 | [5](stage_05.html) |
| 규제(L1/L2) | 계수 크기에 벌점을 주어 과적합을 막는 방법 | [7](stage_07.html) |
| 스코어카드 | 로지스틱 모형을 구간별 점수표로 바꾼 것 | [7](stage_07.html) |
| PDO | 오즈가 2배가 되는 점수 증가량(Points to Double the Odds) | [7](stage_07.html) |
| Factor / Offset | 점수 변환의 기울기 $PDO/\ln 2$ 와 절편 | [7](stage_07.html) |
| 등급(grade) | 점수·PD 를 몇 개 구간으로 묶은 것. 단조 증가하는 부도율이 기대된다 | [7](stage_07.html) |
| 최대우도 추정(MLE) | 관측 데이터가 가장 그럴듯하게 나오는 계수를 고르는 방법 | [6](stage_06.html) |

## 검증과 평가

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| 학습/검증/테스트 | 적합 / 설정 선택 / 최종 1회 평가 | [8](stage_08.html) |
| OOT(Out-of-Time) | 학습 이후 시점의 보류 표본. 시간 안정성 확인용 | [8](stage_08.html) |
| 교차검증 | 데이터를 여러 번 나눠 평가하는 방법. 시계열은 시간 순서를 지킨다 | [8](stage_08.html) |
| 혼동행렬 | TP·FP·FN·TN 의 표. 임계값에 의존한다 | [9](stage_09.html) |
| AUROC | 부도–정상 쌍에서 부도의 점수가 더 높을 확률 | [9](stage_09.html) |
| Gini / AR | $2\times AUROC-1$ (표준 CAP 정의). 조직별 산식을 명시해야 한다 | [9](stage_09.html) |
| KS | 부도와 정상 누적분포의 최대 차이 | [9](stage_09.html) |
| PR-AUC | 정밀도–재현율 곡선 아래 면적. 부도율에 따라 값이 달라진다 | [9](stage_09.html) |
| Brier / log loss | 확률 예측의 오차 지표. 작을수록 좋다 | [9](stage_09.html) |
| 보정(calibration) | 예측확률이 실제 부도율과 맞는 정도 | [12](stage_12.html) |
| DeLong 검정 | 같은 표본으로 평가한 두 AUROC 의 차이를 상관을 반영해 검정 | [14](stage_14.html) |

## 안정성과 운영

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| PSI | 기준·현재 분포의 차이 $\sum(a_i-e_i)\ln(a_i/e_i)$. 경보 기준은 관행 | [10](stage_10.html) |
| CSI | 변수별 안정성 지표(변수 단위 PSI) | [10](stage_10.html) |
| 공변량 이동 | 입력 분포가 변하고 $P(Y\mid X)$ 는 그대로인 변화 | [10](stage_10.html) |
| 개념 변화(concept drift) | 입력과 부도의 관계가 변하는 것. PSI 로 안 보일 수 있다 | [10](stage_10.html) |
| ECL | 기대신용손실 = PD × LGD × EAD | [15](stage_15.html) |
| 모형 카드 | 용도·데이터·성능·한계를 적은 모형 문서 | [15](stage_15.html) |
| MRM | 모형위험관리. 인벤토리·독립검증·모니터링 체계 | [15](stage_15.html) |
| 챌린저 모형 | 현재 모형(챔피언)과 비교하는 대안 모형 | [16](stage_16.html) |

## 머신러닝

| 용어 | 한 줄 정의 | 단계 |
|---|---|---|
| 지니 불순도 | 노드의 섞인 정도. 분할 이득 계산에 쓰인다 | [11](stage_11.html) |
| 그래디언트 부스팅 | 앞선 모형의 잔차를 작은 트리로 순차 보정해 더하는 앙상블 | [11](stage_11.html) |
| 조기 종료 | 검증 손실이 개선되지 않으면 트리 추가를 멈추는 규칙 | [11](stage_11.html) |
| 단조 제약 | 변수가 커질 때 예측이 한 방향으로만 변하도록 모형에 거는 제약 | [11](stage_11.html) |
| SHAP | 개별 예측을 변수 기여도로 가산 분해. 인과가 아니다 | [11](stage_11.html) |
| Platt / Isotonic | 점수를 확률로 바꾸는 사후 보정법 | [12](stage_12.html) |
| 스태킹 | 기본 모형 예측으로 메타 모형을 학습하는 앙상블 | [12](stage_12.html) |
| 합성데이터 | 학습된 모형으로 생성한 인공 데이터. 자동 익명화가 아니다 | [13](stage_13.html) |
| TSTR | 합성으로 학습하고 실제로 평가하는 유용성 검사 | [13](stage_13.html) |
| DCR | 합성 행과 가장 가까운 원본 행의 거리. 복제 탐지용 | [13](stage_13.html) |
