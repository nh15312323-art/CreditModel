# 방법론 요약

| 항목 | 이 프로그램의 선택 | 이유 |
|---|---|---|
| 부호 | target 1=부도, WOE=ln(%bad/%good) | 계수가 양(+)이면 위험 증가로 읽기 쉬움 |
| 분할 | 시간 기준 개발/검증/OOT | 미래 정보 누수 방지 |
| 비닝·대체값 | 개발 구간에서만 적합 | 누수 방지 |
| 모형 | 규제형 로지스틱 + 챌린저(부스팅) | 설명 가능성과 변별력 비교 |
| 평가 | AUROC/Gini/KS/Brier/보정 + 신뢰구간 | 변별력과 확률 정확성 분리 |
| 안정성 | PSI(기준 경계 고정) + 성능 모니터링 | 분포 변화와 관계 변화 구분 |
| 문서 | 모형 카드, 목표 정의서, 데이터 사전 | 검증·감사 추적 |

각 선택의 근거는 `docs/theory/` 의 해당 단계 페이지에 있다.
